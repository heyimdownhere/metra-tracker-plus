# Icon mockups

Saved design work for the app icon (Nov 13). Open any `.html` file in a browser to see that set; the `.png` files are screenshots of them.

| File | What it is |
|---|---|
| `icon-mockups.png` / `index.html` | First flat options A–F, plus Metra/CTA switch symbols |
| `icon-3d.png` / `3d.html` | 3D train options G, H, I |
| `icon-night.png` / `night.html` | Night version in six looks (I1–I6) |
| `icon-neon.png` / `neon.html` | Neon + city lights, N1–N4 (**N2** saved for later) |
| `icon-chicago.png` / `chicago.html` | N2 with a Chicago skyline, C1–C3. **C1 is the app icon.** |
| `icon-square.svg` | C1 as a full-square SVG (source of `web/icon-*.png`) |

The app's icon files (`web/favicon.svg`, `web/icon-192.png`, `web/icon-512.png`, `web/apple-touch-icon.png`) were generated from C1 in `chicago.html`.
